A PHP and MySQL photo gallery and blog site.

## What it does

- User registration, login and profiles.
- Public and private galleries, image pages with comments, a random image page
  and a top 10.
- A blog page, a contact page and an admin page.
- Rich text editing with TinyMCE.

## Tech

- PHP and MySQL
- JavaScript (TinyMCE)

## Running

Serve the folder with a web server that has PHP, and a MySQL database where the
code uses one (see `connect.php` or `db_mysql.php`).
